# BOOTH Free Collector 拡張 v2.5

Chromeで単体利用できる拡張です。Windowsアプリは必須ではありません。

1. このフォルダを通常の場所に展開します。
2. Chromeの chrome://extensions を開き、開発者モードの「パッケージ化されていない拡張機能を読み込む」で、このmanifest.jsonがあるフォルダを選びます。
3. 拡張を開き「新着の確認を有効にする」を選んで保存します。初回の過去分と定期取得は衣装・髪型のみです。カテゴリ設定欄はありません。
4. BOOTHへのログインは普段のブラウザで行います。拡張はCookieの値を取り出したりWindowsアプリへ渡したりしません。ログインが切れた場合は保留し、本人のログイン後に「再開」を押します。

拡張だけなら、ブラウザのDLフォルダ内のBOOTH-Free-Collectorに保存します。Windowsアプリも起動していれば自動で連携し、Windows側で設定したフォルダへ直接保存します。連携時はDownloadsを経由しません。既存ファイルの重複も確認します。連携中も拡張で取得するカテゴリは衣装・髪型のみで、さらにWindows側の条件を適用します。

一覧通信は12時間に1度まで。再起動・手動の再開・モード変更で早めません。ブラウザが完全終了中は保留し、次に起動した際に再開します。BOOTHページのタブを自動で開く動作はありません。

必要な権限: ローカル設定・履歴、定期処理、ダウンロードと履歴、画面を開かないHTML解析、Windowsとの任意連携、通知、一覧・履歴を保持するローカル容量。サイト権限はBOOTH、BOOTHのファイル配信元、専用Cloudflare配信元だけです。Cookieを読む権限はありません。
