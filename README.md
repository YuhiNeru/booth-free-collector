# BOOTH Free Downloader v3.0.6

無料商品の公開カタログを受け取り、選んだカテゴリのファイル取得から公式BOOTH Library Managerへの一覧登録まで自動で行うWindows常駐アプリです。v3からブラウザ拡張は不要です。

## 必要なもの

- Windows x64
- 公式BOOTH Library Manager(インストール済み。保存先は取得前に公式設定で指定)
- Microsoft Edge WebView2 Runtime
- BOOTHの規約に沿って利用できる本人のアカウント

.NET 10.0.14は同梱します。初回はインストール先と署名を裏で判定し、公式Managerを起動せずに専用ログインを準備します。実際に取得・一覧登録が必要なときだけ公式Managerを起動し、実行中の公式設定から保存先を確認します。

## 初回セットアップ

画面上部のランプは「導入確認 → ログイン → 接続確認 → 完了」の順です。水色と「いまここ」が現在の工程、緑と「確認済み」が終わった工程です。セットアップ未完了の間はこの専用画面だけを表示し、完了後に通常メニューを利用できます。

1. ZIPを展開して `BoothFreeDownloader.exe` を起動します。
2. 導入確認は自動で行います。未導入なら公式案内から入手して「① 導入を確認する」を押します。この判定で公式Managerは起動しません。
3. 赤い「サブアカウントでお願いします」と説明を読み、「② ログイン画面を開く」を押し、規約に沿って使える専用アカウントで、アプリ内の公式BOOTHログイン画面へログインします。普段のChromeのCookieは取り込みません。
4. 公式画面でログインできたら、同じ場所の主ボタン「③ ログインできたので接続を確認」を押します。ログイン状態はアプリ専用のWebView2領域へ保存され、次回起動も有効な間は再利用します。期限切れやアクセス確認時は本人の操作を待ちます。

サブアカウントはメインアカウントへの影響を分けるための案内で、安全性や規約上の許可を保証するものではありません。共通規約は複数アカウントを条件付きで認めていますが、自動取得専用の使い分けが公認されているとは説明していません。

## 保存先と公式アプリ

保存先は公式Managerの「設定 → データの保存場所」だけで変更します。Downloaderに独立した保存先設定はありません。公式側の変更に追従し、読み取り失敗・設定の矛盾・自動起動後の保存先の不一致では待機します。別のCドライブフォルダへ代替保存しません。

画面は昔のTwitterのダークブルーに近い濃紺と水色のアクセントで統一しています。右上の「詳細:OFF」「詳細:ON」で、右側の専用説明エリアを切り替えられます。初期値はOFFで、選択は次回起動にも引き継ぎます。ログインの注意、処理状況、保存先やエラーは非表示になりません。

公式Managerを起動して取得用のURIを渡す前に、コード署名と発行元を確認します。公式アプリ自身が取得・展開・一覧登録します。Downloaderは公式DBへ書き込まず、ファイル選択による手動インポートも不要です。

## 取得カテゴリ

「ダウンロード対象」で、優先度ごとの一括選択と個別チェックを使えます。

| 優先度 | 対象 | 初期値 |
|---|---|---|
| 高 | 衣装、髪型 | ON |
| 中 | 3Dキャラクター、テクスチャ、装飾品、小道具、3Dモーション・モーション | OFF |
| 低 | ワールド系、ツール類 | OFF |

初期対象は初回・定期とも衣装と髪型です。対象を追加して過去分も取得する場合は、「過去分を追加」を使います。全項目を外すと取得しません。カタログにない商品や、無料リンクが確認できない商品は取得しません。

## スケジュールと常駐

VPS巡回とPCのカタログ本文取得はそれぞれ12時間以上空け、失敗や再起動で間隔をリセットしません。本文取得が可能になった後は公開配信の更新ヘッダーを最短5分間隔で確認し、更新検知後65秒待って本文を取得します。この確認でVPS巡回やBOOTHへの問い合わせは起動しません。

常駐側は、初回の過去分に開始から12時間、通常分にカタログ公開から4時間の期限を持たせ、5〜90秒の間隔・同時要求2件までに調整します。手動の過去分追加は依頼時刻から4時間です。期限は負荷分散の目標で、PC停止・認証待ち・障害中の完了保証ではありません。

このチャットや普段のブラウザを開いておく必要はありません。PC上のDownloaderが動作し、取得時には公式Managerを起動できる必要があります。×で通知領域へ格納し、終了は通知領域メニューから行います。Windowsログイン時の常駐と公式Managerの自動起動は設定で選べます。

## 認証データと旧版からの移行

設定・履歴は `%USERPROFILE%\.booth-free-collector`、専用ログイン領域はその下の `session-profile` です。この領域にはCookieなどの機密情報が含まれるため、診断資料や公開ZIPへ含めないでください。「ログアウト・認証データを削除」で専用領域のブラウザデータを消去します。ダウンロード済みの商品は削除しません。

v2以前のChrome/Edge拡張は削除してください。v3は拡張の接続登録を解除し、Native Messaging経由の処理を受け付けません。以前の保存先・取得済み履歴・初回期限・カタログ取得時刻は維持します。

認証を内蔵したことで、Downloader自身が認証状態を扱えるアプリになります。OSSであることや専用アカウントだけを根拠に安全とは説明しません。制約は[SECURITY.md](SECURITY.md)、検証結果は[VALIDATION.md](VALIDATION.md)を参照してください。

## 開発・確認

```powershell
dotnet publish BoothFreeCollector -c Release -r win-x64 --self-contained true -o dist/test-runtime
node --test tests/worker.test.mjs
python -m unittest discover -s tests -v
```

配布用実行ファイルの `--self-test <新しい専用フォルダ>` はローカル自己検証、`--session-self-test <新しい専用フォルダ>` は架空Cookieと模擬応答を使った実WebView2検証です。本人のセッションや実商品を使いません。GUI実行ファイルの終了を待って `result.json` を確認してください。`--collector-status` は保存済み状態と公式設定の読み取り専用診断です。

画面は左側のメニューで切り替えます。時計の更新で一覧や選択を作り直さず、公式設定の確認とファイル照合を画面操作から分離しています。右上の「詳細:OFF」「詳細:ON」で専用の補足説明エリアを切り替えられます。ログインの注意やエラーは常時表示します。

内部の設定フォルダ名とプロジェクト名は互換性のため旧名を維持しています。設定の実体はユーザーホームのロケーターで固定し、起動元が変わっても同じ設定と専用セッションを使います。既存の専用領域は同一ドライブ内で移動し、認証情報の複製はしません。別ドライブの場合は元の実体パスを保持します。

アイコンは独自のダウンロード矢印です。16〜256ピクセルのWindowsアイコンを実行ファイルと通知領域に使用します。元データは`BoothFreeCollector/assets/app.svg`、再生成はPillowを用意して`python BoothFreeCollector/assets/create_icon.py`で行えます。

「導入を再確認」を手動で押したときだけ、ボタンと案内文に「確認中…」を表示します。定期確認では表示を切り替えず、結果に変化があれば更新します。完了すると結果に切り替わります。確認中の重複操作は防ぎ、取得時の公式アプリ起動直後など、一時的な準備待ちは短い間隔で再確認します。署名や保存先が一致しない場合の停止は維持します。

公式アプリの自動起動は、署名確認済みの実行ファイルを直接起動します。正常確認後に公式アプリを閉じた場合、直前の起動時刻だけで1分間待たせることはありません。確認が15秒を超えたら待機案内へ切り替え、再確認しても進行中の処理を重複実行しません。

初回確認・専用ログイン・定期的な待機確認だけでは公式Managerを起動しません。対象の取得や未確認の一覧登録を処理するときだけ起動します。保存先は取得・一覧登録の直前に確認する旨を画面へ表示します。

セットアップが必要な状態に戻った場合も通常メニューを隠し、専用画面へ戻します。ログイン中は②、接続確認の実行中は③が点灯し、検証が通ると④が緑になります。完了後はログイン画面を隠し、「ダウンロード画面へ」を表示します。補足説明は専用エリアへまとめて初期状態を非表示にし、赤い注意と必要な操作案内は常に残します。

## 画面ごとの詳細

右上の詳細ボタンは開閉状態を維持し、説明の見出しと内容は現在の画面に合わせて切り替わります。

- ダウンロード: 待機中の商品、取得状況、再開・停止・過去分の追加
- 設定: 保存先、カテゴリ画面への案内、一覧の取得間隔
- ダウンロード対象: 初期の対象カテゴリ、選択の保存、過去分の追加
- セットアップ: ログイン状態の保持と期限切れ、工程ランプの読み方
